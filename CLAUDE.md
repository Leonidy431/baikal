## Linux на Android: Terminal и Termux (2026-11-26)
- **Terminal** — приложение Android (AVF), не функция GrapheneOS; есть и на обычном Pixel. Это Debian в виртуальной машине; образ (от ~500 МБ) качается с серверов Google. На Pixel 10 — почти нативная скорость и GPU-ускорение, но графика с серьёзными ограничениями. В GrapheneOS пакет `com.android.virtualization.terminal`, поведение то же.
- **Включение (по памяти оператора, источниками не подтверждено):** режим разработчика → Настройки → Система → Параметры разработчика → «Среда разработки Linux». Внутри: `apt install nodejs npm git`, затем `npx skills …`.
- **Termux** — нативный userland, минимальные накладные расходы, F-Droid/GitHub, файлы через `termux-setup-storage` (в Terminal — `/mnt/shared`). Для `npx skills` годятся оба; для быстрого старта — Termux.
- Полная справка и план для VM8: `Leonidy431/webtypicon2` → `docs/version-3.0/HLD/docs/ru/HLD_ДЕКЕЙ_VM8_ИНСТРУМЕНТЫ_NODE_SKILLS_2026-11-26.md`. Источники: reddit.com/r/Android/comments/1obt3vf · android.gadgethacks.com (Pixel 10 GPU acceleration) · discuss.grapheneos.org/d/30425 · discuss.grapheneos.org/d/42966 · github.com/termux/termux-app/releases

## 🗓️ Еженедельный разбор долгов — по четвергам (2026-11-26)

Оператор (2026-11-26, дословно): «Во все репо Пропиши ветку новую и правило Клауд мд. Раз в неделю. В четверг. Что ставить по декей в долг. Почитай из архива весь talklog и найди и поставь мне долги».

1. **Когда.** Раз в неделю, в четверг: задание по расписанию на аккаунт запускает свежую сессию Claude. Кроме того, разбор делается в любой сессии, которая в четверг работает с этим репозиторием.
2. **Что читать.** Весь TALK_LOG репозитория (`TALK_LOG*.md`, переписки, заметки сессий), а также архивные ветки `archive/*` и `backup/*`. Ищутся просьбы оператора без отметки о выполнении, обещания, блокеры, «в долг» и «в бэклог».
3. **Три вида долгов.**
   - **Оператора.** Только он может это сделать: доступы, ключи, деньги, консоль GCP, железо, решения и лицензии.
   - **Декея** (`llama-pipeline-operator` на VM8). Рутинная детерминированная работа по расписанию: проверки очередей, синхронизации и rclone, отчёты о состоянии, повторные прогоны, проверки здоровья.
   - **Claude.** Код, переводы, HLD, аудиты.
4. **Куда записывать.** Только новая ветка `claude/weekly-debts-<ГГГГММДД>` и PR, в `main` напрямую не пушить. Каждый долг записывается со ссылкой `файл:строка` и дословной цитатой; цитаты не выдумывать. Долг декея становится задачей декея (в webtypicon2 это `llama-pipeline-operator/decay-debts.json`). Долги оператора приходят ему одним коротким списком.
5. **Закрытие.** Долг закрывается только по доказательству: коммиту, прогону или слову оператора. Молчание долг не закрывает. Если новых долгов нет, ветка не создаётся.
